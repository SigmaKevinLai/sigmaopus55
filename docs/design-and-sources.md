# SIGMA website — design system and content sources

## Positioning
This site is the company's replacement website. All copy is written in the company's own voice. It contains no "unofficial" wording and no links to the old site.

## Design system
- **Palette:**
  - graphite `#191c1b` / `#161918`
  - paper `#f4f3ee`
  - tone `#e8e7df`
  - molten orange `#f16b40`, used only for accents, key actions and molten metal
  - text uses `#b23d17` where orange must sit on a light background
- **Type:**
  - body: Noto Sans TC, 17 px base (16.5 px on phones), line-height 1.75
  - display / numerals: Barlow Condensed
  - All fonts are self-hosted under the SIL OFL. The CJK subset is 408 KB, uses `font-display:swap` and is not preloaded, so system CJK text paints first.
- **Illustration:** isometric technical line art generated by `tools/art.py` from geometric solids. Face fills come from CSS, so each drawing works on both light and dark sections. All drawings are original. No photographs are used until licensed company photography is supplied.
- **Layout:**
  - 1240 px max wrap
  - numbered section heads (`01 產品與服務`)
  - hairline grids and spec tables styled like engineering data sheets
- **Interaction (progressive enhancement):**
  - mobile menu with focus management
  - `details`-based language menu
  - sticky product TOC with scroll spy
  - ADC comparison that highlights differing cells
  - Q&A search with highlight and empty state
  - location filter
  - validated inquiry form that opens a prefilled email to info@sigmasha.com, with a copy fallback
- **Accessibility features in place:**
  - skip link, landmarks, one h1 per page
  - `aria-current`, live regions, inline errors linked by `aria-describedby`
  - 44 px targets
  - forced-colors, reduced-motion and print styles
  - automated axe run: 0 violations on 9 pages (not a WCAG certification)
